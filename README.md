# Node.js Practice Projects

## About This Repository

This repository contains my Node.js learning exercises and practical projects developed during my Full Stack Development training.

It covers core Node.js modules, file system operations, HTTP servers, streams, URL handling, and backend development with Express.js and MongoDB.

## Technologies Used

- Node.js
- JavaScript
- Express.js
- MongoDB
- Mongoose
- HTML5
- CSS3

## Topics Covered

- Node.js Core Modules
- File System (FS) Module
- HTTP Module
- URL Module
- OS Module
- Crypto Module
- Query String Module
- Streams
- HTTP Methods
- Express.js Basics
- MongoDB Integration
- Employee Management CRUD Operations

## How to Run

1. Clone this repository.
2. Open the required project folder.
3. Install dependencies using:

   `npm install`

4. Configure environment variables if required.
5. Run the project using the appropriate command in its `package.json`.
